# ⛅ Weather Website

A responsive weather web application that provides real-time weather updates for any location.
It fetches data from a public API and displays current conditions, temperature, humidity, wind speed, and more.



---

## 🌟 Features

- 🌍 Get weather by city name or current location
- 🌡️ Temperature, humidity, wind speed, and conditions
- 📍 Geolocation support (with permission)
- 🎨 Beautiful and responsive UI
